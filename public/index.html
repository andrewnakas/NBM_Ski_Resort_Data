Understanding Probability Bands

  • 95% Line: There's a 95% chance the actual value will be at or below this level
  • 90% Line: There's a 90% chance the actual value will be at or below this level
  • 50% Line (Median): Equally likely to be above or below this value
  • 10% Line: There's only a 10% chance the actual value will be at or below this level
